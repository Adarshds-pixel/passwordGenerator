# Password Generator

A simple password generator built with HTML, CSS, and JavaScript. It creates two 15-character passwords using letters, numbers, and symbols. Click a password to copy it.

## Use

1. Open `index.html` in a browser.
2. Select **Generate Passwords**.
3. Click either password to copy it.

Clipboard access may require running the page on `localhost` or over HTTPS.

## Project files

- `index.html` — page structure
- `index.css` — styling and responsive layout
- `index.js` — password generation and copy behavior

## Note

This project uses JavaScript's `Math.random()` and is intended for learning. Do not rely on it to generate passwords for sensitive accounts.
